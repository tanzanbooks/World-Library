# 🌏 World Library 2.0
## 世界の図書館構想2.0

### 古本屋のデータベースから、AI時代の「知のインフラ」をつくる

**World Library 2.0（世界の図書館構想2.0）**は、世界中に分散している本・人・場所・知識をデータによって結び、誰もがAIを通じて知識を探索できるネットワークをつくるプロジェクトです。

世界中の本を一か所に集めた巨大な図書館をつくることが目的ではありません。

本は世界中に散らばっていていい。

図書館にもある。  
大学にもある。  
古本屋にもある。  
個人の本棚にもある。  
小さなシェア本棚にもある。

それらをデータとコードによってつなぎ、AIを通じて人間が知識と出会える仕組みをつくります。

---

# 🏠 17坪の古本屋から始める

最初から世界中の図書館をつなぐことはできません。

そこで、このプロジェクトでは小さな実験から始めます。

最初の実験場は、神奈川県相模原市にある**二の橋書店**です。

一冊の古本には、

- 書名
- 著者
- 出版社
- 出版年
- ISBN
- ジャンル
- 価格
- 棚の場所

などの情報があります。

さらに、

- 誰がこの本を選んだのか
- なぜこの棚に置いたのか
- どんな本と一緒に読むと面白いのか
- この本をテーマにどんなイベントを開催したのか
- この本に関連する人物や場所はあるのか

といった情報を結びつけます。

そうすることで、単なる「古本の在庫データベース」から、**本を中心とした知識のネットワーク**へ発展させることを目指します。

# 🔗 本のデータベースからKnowledge Graphへ

将来的には、本だけではなく、

```text
本
↓
著者
↓
人物
↓
地域
↓
歴史
↓
出来事
↓
関連人物
↓
別の本
```

というように、情報同士の「関係」をデータとして表現します。

目指す流れは、

```text
本棚をデータベース化する
        ↓
データベース同士を接続する
        ↓
Knowledge Graphにする
        ↓
AIから自然言語でアクセスする
```

というものです。

# 🤖 AIによる「知識との対話」

将来的には、検索窓に書名や著者名を入力するだけではなく、普通の言葉で質問できる仕組みを目指します。

たとえば、

> 昭和30年代の日本について知りたい

と質問すると、

> 二の橋書店には関連する本があります。  
> まず、この3冊から読んでみてください。

とAIが案内する。

さらに、

> この本を書いた人物について知りたい

> このテーマに詳しい棚主は？

> 関連するイベントは？

> 近所に関係する史跡は？

と対話を続けられる。

**「検索」から「知識との対話」へ。**

これがWorld Library 2.0の目指す方向です。

# 📊 現在の実装：知識循環ダッシュボード

World Library 2.0の最初の実装として、**Python + Streamlitによる「知識循環ダッシュボード」**を開発しています。

金融データ分析の考え方を、

- 図書館
- 古本屋
- 読書会
- 一箱古本市

へ応用し、知識循環を可視化することを目的としています。

- SNS効果分析

# 💻 知識循環ダッシュボードの使い方

## 1. インストール

WindowsのコマンドプロンプトまたはPowerShellで、このリポジトリを保存したフォルダへ移動して実行します。

```bash
python -m pip install -r requirements.txt
```

## 2. 起動

```bash
streamlit run app.py
```

ブラウザが開いたら、左側から `sample_data.csv` または自分のExcelファイルを読み込みます。
